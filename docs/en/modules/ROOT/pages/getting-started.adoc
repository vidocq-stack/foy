= Getting started
:description: First `HttpServlet` served by Foy on top of Chappe.

== Prerequisites

* **Java 25**, **Maven 4.0.0-rc-5** — `.sdkmanrc` at the repo root.
* Familiarity with Jakarta Servlet 6.1.

== Maven coordinates

[source,xml]
----
<dependencies>
    <dependency>
        <groupId>jakarta.servlet</groupId>
        <artifactId>jakarta.servlet-api</artifactId>
    </dependency>
    <dependency>
        <groupId>io.vidocq.foy</groupId>
        <artifactId>foy-core</artifactId>
        <version>0.1.0-SNAPSHOT</version>
    </dependency>
    <dependency>
        <groupId>io.vidocq.foy</groupId>
        <artifactId>foy-chappe</artifactId>
        <version>0.1.0-SNAPSHOT</version>
        <scope>runtime</scope>
    </dependency>
</dependencies>
----

== Hello world

[source,java]
----
package io.example;

import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import java.io.IOException;

@WebServlet("/hello/*")
public class HelloServlet extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        var name = req.getPathInfo() == null ? "world" : req.getPathInfo().substring(1);
        resp.setContentType("text/plain;charset=UTF-8");
        resp.getWriter().write("Hello, " + name + "!");
    }
}
----

Bootstrap:

[source,java]
----
import io.vidocq.foy.chappe.FoyChappeBoot;

void main() throws Exception {
    try (var server = FoyChappeBoot.builder()
            .port(8080)
            .servlet(new HelloServlet(), "/hello/*")
            .build()) {
        server.start();
        Thread.currentThread().join();
    }
}
----

== `web.xml` or annotations?

Foy supports both. `@WebServlet`, `@WebFilter`, `@WebListener` are discovered at compile time by an APT (no classpath scan at startup). A `WEB-INF/web.xml` can complement or override via the standard `metadata-complete` flag.

== Build and run

[source,bash]
----
sdk env
./mvnw -ntp install -DskipTests
java -jar target/myapp.jar
----

====
Official Jakarta Servlet 6.1 TCK: `./run-official-tck-servlet6.1.sh --all` from the `foy` repo root. `foy-tck` module is out-of-reactor.
