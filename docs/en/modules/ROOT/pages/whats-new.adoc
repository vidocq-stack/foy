== CDI

* **The request context is active for each request** — when `FoyChappeBoot` is given a `BeanManager`, Foy activates the CDI request context around each request, through the standard `RequestContextController`, so `@RequestScoped` beans work in servlets, filters and listeners, and the container fires the request context events. {release-version} activated it under no container, Vauban included: a `@RequestScoped` bean failed with `ContextNotActiveException` (BUG-20261010-01). The session context is not activated. xref:reference.adoc#other-containers[Other CDI containers].
* **Proven on Weld SE** — the new `foy-it-weld` module, never published, runs Foy on Chappe with Weld SE 6.0 without `foy-cdi-vauban`: servlets, filters and listeners get injection, request-scoped beans live per request (foy#18). xref:reference.adoc#other-containers[Other CDI containers].
