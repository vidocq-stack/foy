== CDI

* **The request context is active for each request** — when `FoyChappeBoot` is given a `BeanManager`, Foy activates the CDI request context around each request, through the standard `RequestContextController`, so `@RequestScoped` beans work in servlets, filters and listeners, and the container fires the request context events. {release-version} activated it under no container, Vauban included: a `@RequestScoped` bean failed with `ContextNotActiveException` (BUG-20261010-01). The session context is not activated. xref:reference.adoc#other-containers[Other CDI containers]. Under Vauban, which has no `RequestContextController` yet, it is not (link:https://codefloe.com/Vidocq/vauban/issues/147[vauban#147]).
* **Proven on Weld SE** — the new `foy-it-weld` module, never published, runs Foy on Chappe with Weld SE 6.0 without `foy-cdi-vauban`: servlets, filters and listeners get injection, request-scoped beans live per request (foy#18). xref:reference.adoc#other-containers[Other CDI containers].
* **`@SessionScoped` on Vauban** — the session context is active for each request: `@SessionScoped` beans live in the `HttpSession` and are destroyed with it, with the `@Initialized`, `@BeforeDestroyed` and `@Destroyed(SessionScoped.class)` events. Vauban's new `vauban-webcontexts` provides the context and `foy-cdi-vauban` drives it; nothing to configure. A session-scoped bean used to fail with `ContextNotActiveException` (foy#21). xref:reference.adoc#other-containers[Other CDI containers].
* **`CdiContextListeners`, a service for the adapters of CDI implementations** — Foy registers the listeners a provider gives for the `BeanManager` it is given, ahead of the application's listeners. xref:reference.adoc#other-containers[Other CDI containers].
* **Weld's servlet integration runs on Foy** — `weld-servlet-core`'s initializer starts Weld, which manages the request and session contexts itself. `foy-it-weld-servlet` uses it as the reference for the session scope, and `foy-it-vauban-session` runs the same scenarios on Vauban. xref:reference.adoc#other-containers[Other CDI containers].
