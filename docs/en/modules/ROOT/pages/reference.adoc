== Maven artefacts

[cols="1,3"]
|===
| Artefact | Role

| `io.vidocq.foy:foy-api:0.1.0-SNAPSHOT`
| Public API

| `io.vidocq.foy:foy-core:0.1.0-SNAPSHOT`
| Servlet engine (web.xml parser, listeners, security, request/response bridges)

| `io.vidocq.foy:foy-chappe:0.1.0-SNAPSHOT`
| Bridge to Chappe (`FoyChappeBoot`, `ChappeServletBridge`)

| `io.vidocq.foy:foy-cdi-vauban:0.1.0-SNAPSHOT`
| Build-time CDI integration with Vauban (`FoyVaubanBootstrap`)
|===
