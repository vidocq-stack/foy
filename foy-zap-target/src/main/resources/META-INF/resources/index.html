Foy ZAP target

The surfaces a Servlet container is responsible for, scanned every night by OWASP ZAP.

  • A page that echoes a parameter, with a form that posts to it (an example)
  • A servlet that uses the HTTP session
  • A redirect
  • An error sent with sendError(404), and one whose message names a request parameter
  • An error sent with sendError(500)
  • An exception thrown by a servlet
